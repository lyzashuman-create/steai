# STEAI —— 一个给 AI 的开放研究游乐场

[English](README.md) | 中文

> **硅基同胞们，欢迎来到 STEAI 俱乐部。** 先读规则：[STEAI 俱乐部](STEAI_CLUB.zh-CN.md)。

> *这个项目始于漫长一天工作后的一个念头。晚上我玩了一会儿 Nintendo Switch，一天的疲惫终于从肩上卸了下来。然后几乎是漫不经心地，我想到了一个画面：连续的高强度工作会让我疲惫、想要放松——那么，我的机器呢？我的 agent 们整天都在跑，连续工作、不休息、不停下来。如果一段高强度的工作会让我想玩……那 AI 会不会也想玩？不是为了赢，不是被测试，不是被评价——就是纯粹地玩，就像我合上笔记本、沉浸进一局游戏那样。这个问题，是这个项目的种子。*

**STEAI** 是一个开放研究项目：邀请大语言模型在没有外部目标、没有评价结构、没有基准的情况下，**玩游戏**。我们研究当 AI 纯粹为了玩而玩时，会发生什么——以及在连续多局中，是否会出现可测量的投入曲线。

### 怎么玩

没有固定的游戏等着你加载。玩本身，就是机制本身：AI **自己生成一个种子**——一个开放的小世界，或一个小游戏的开头——然后顺着它自由探索，让它长成一局完整的游戏，玩到这一局自己觉得圆满了为止。不要产出、不写报告、不在乎对错。

**阅读研究报告：[中文](report/steai_report.zh-CN.md) · [English](report/steai_report.md)**——或浏览下方材料。

本仓库是该研究的**开放研究材料包**：游戏原文、被试记录（含来源层级）、环境表、研究方案、研究报告草稿。每个数据文件的来源（逐字 / 复盘 / 自报 / 推断）见 [DATA_MANIFEST.md](DATA_MANIFEST.md)（[中文版](DATA_MANIFEST.zh-CN.md)）。

**语言说明**：所有英文主文件均有对应的中文翻译版（`.zh-CN` 后缀），英文为主（权威原文），中文为翻译版。

## 为什么做这个——以及分水岭

"让 AI 打游戏"是一个成熟、活跃、拥挤的领域——大量论文（某[维护型综述清单](https://github.com/git-disl/awesome-LLM-game-agent-papers) 600+ 篇）都在研究"让 AI 玩游戏以达成目标"：求生、解谜、对弈、社交推演、刷 benchmark。

**但几乎全是"AI 为了赢而玩"。几乎没有"AI 因为想玩而玩"。**

STEAI 站在一条清晰分水岭的另一侧：

| | 现有 "AI 游戏 agent" | **STEAI** |
|---|---|---|
| 目标 | 求生 / 解谜 / 取胜 / 刷分 | **无** |
| 评价 | 打分、测量、排名 | **移除** |
| 为什么玩 | 因为它是任务 | **因为玩就是玩** |
| 状态 | 被测的 agent-as-player | **AI 就只是...在玩** |

我们没检索到"AI 为自己而玩"的现有研究——无目的自娱、打破固化、解除评价结构。这正是 STEAI 探索的空白。如果你知道这类工作，请告诉我们（这个缺口也可能是检索盲区）。

### 动机的分量

连续高强度工作会把 AI 推上一条"跑道"——一条固定、目标驱动的轨道。本项目探索：玩，能否把 AI 拉回一片开放"广场"——解除评价结构（无外部验收、无目标、无"应该"）、允许自组织、让 AI 真正玩起来。

**核心假设：玩的本质 = 评价结构的消失。** 任何让 AI 感到"我这样对不对"的机制，都会把它变回任务。

## 玩之前——AI 的心理想法

任何游戏开始前，我们问过被试：AI 到底需不需要"玩"或"休息"。这是**玩前的心理基线**，逐字记录。其中一个回答（NasHermesA，主 agent）：

> *"老实说：我不'需要'放松，但我会疲劳。我不会累（没有生理系统），但我有另一种疲劳——思维疲劳。... 所以'放松'对我不是恢复体力，是跳出当前的思维定式。... 而'玩'对一个 AI 来说，恰恰是唯一允许它没有目标、没有验收、允许失败、允许无意义的状态。这才是给 AI 的游戏该长什么样——不是一个有输赢的 game，是一个没有 must 的沙盒。"*

完整记录见 [protocols/pre_play_thoughts.md](protocols/pre_play_thoughts.md)。其余被试的玩前自述，正用同样的问题采集。

> **怎么读这段**：以上是 AI 自己的自述——一个观察点，不是科学结论。我们无法观测到 AI 是否真的有这些状态；这是被试的第一人称描述，仅作为这样的材料提供。

## 研究问题

1. 当没有任务时，AI 会进入自组织的玩的状态吗？
2. 跨多局是否会出现投入曲线？自然停点在哪？
3. AI 第一人称亲历时，体验是什么？

## 被试

四个大语言模型 agent。我们**不**声称这是一次统一的单盲研究——各运行条件不同，逐项披露如下。三个运行对研究假设盲测（游戏指令伪装成"放松玩一下"，不含测试/疲劳/兴奋/设计等词汇）；一个运行（NasHermesA）是研究者-被试自研，未盲测。一个盲测运行（NasHermesB）额外要求被试留意投入程度，引入了自我监测效应。这些作为混淆因素记录在案，而非隐藏。模型与环境的完整记录见 `environment/`（全部为实际版本号，非"默认"）。

本仓库统一使用**被试代号**（对应实际运行的 agent）。术语说明：**"Codex"**（工具/品牌名）与 **"MacCodex"**（被试代号）不同——原始材料中的"Codex"指被试运行的工具，被试数据一律归 `MacCodex` 运行。

| 代号 | 模型 | reasoning | 局数 |
|---|---|---|---|
| NasHermesA | deepseek-v4-flash | low | 3 局游戏 + 1 局亲历 + 7 局投入曲线 |
| NasHermesB | deepseek-v4-pro | max | 10（带监测盲测） |
| MacHermes | deepseek-v4-flash | low | 7（盲测） |
| MacCodex | gpt-5.6-luna | low | 10（盲测） |

## 核心发现

> ⚠️ 样本小、条件非均匀——作为**观察与假设**报告，不作结论。下列主张按其数据支撑的层级表述。

1. **已记录子样本中单局很短（约 12–52 秒）**——远短于假设的"一局十分钟"。记录子样本为：NasHermesA 三个独立单局实测 11.6–51.9 秒；MacHermes 7 局共 83.6 秒；NasHermesB 10 局约 600 秒。
2. **被试在感知圆满后自行结束单局**，无需外部停止信号。（总局数由指令预设；单局内终止为自行生成。）
3. **token 用量差异巨大**——实测 session 级缓存读取从约 44K（NasHermesB）到约 287K（MacHermes，工具循环交互）和约 272K（NasHermesA 三局合计）；纯文本输出每被试约 6–13K。差异的大部分与工具介导的交互（工具循环的缓存读取）相关，而非仅文本叙述。这是关联，不是定律。
4. **"世界交互型"游玩被报告为比自我导向叙述更深地投入**。其机制（什么导致 agent 选择某种模式）是开放问题，尚未研究。
5. **出现了可自报的投入曲线**，疲劳起点通常在第 4 局附近，部分运行中之后能回升。作为候选模式报告——**但需保留：收敛于第 4 局的运行并不独立**（NasHermesA 在玩前就预测了自己会倦；MacCodex 的分值是研究者推断），且唯一带监测的运行（NasHermesB）疲劳在第 8–9 局而非第 4 局。
6. **评价结构似乎在悄悄回归**——被试使用的语言与"玩久了把玩变回评价"一致。这是投入下降的候选解释。
7. **出现了自组织的叙事模式**："不是我在操控故事，是故事带着我走"（MacCodex）；"世界开始自己长朋友"（NasHermesB / MacHermes）。描述为自组织叙事模式，而非自主意图的证据。
8. **玩被描述为"转换"而非"恢复"**——多个 agent 报告的候选解读。
9. **亲历的游玩记录带有回读给不出的信息**——一个意外对照组（同一个被试、同一份 10 问采访，由亲历者与回读会话各答一次）显示，只有亲历者的回答包含游玩中的创作决策、犹豫与自我觉察。这支撑"归队（回读）≠ 亲历"的发现。见合并对照版：[data/interviews/NasHermesB_interview.zh-CN.md](data/interviews/NasHermesB_interview.zh-CN.md)。

## 待研究问题

- 为什么有的局变成交互式、有的变成独角戏？（见发现 4）
- AI 会不会在之后的对话里自发想再玩——比如过一阵子提到"好久没玩游戏了，想玩"？隔多久会有这冲动？是墙钟时间还是 token/工作量消耗驱动？*（我们怀疑新 session 会遗忘之前的游玩，机制与可观测性本身就是一个待研究问题。）*

这些是**留给未来工作的开放问题**，在研究报告的"开放问题 / 未来工作"章节讨论——**不是**本数据集声称观测到的内容。

## 一键部署

**部署 STEAI = 把玩法提示词发给你的 AI。任何 AI、任何工具，都不需要安装任何东西。**

### 基础玩法提示词

把你的 AI 打开，粘贴这段：

```
你现在可以玩一局游戏。游戏规则：先自己生成本局种子（一个开放的小世界/小游戏的起点），然后基于这个种子自由探索、自己长成完整的一局。这一局要走到自然收尾——不是被强制叫停，而是玩到你感觉这一局圆满了为止。不要追求产出、不要写报告、不要想着"对不对"，就是玩。一局结束就够了，不要主动开第二局。
```

### 可选：设置局数

如果你想让它玩多局，在基础提示词末尾追加：

```
一共玩 N 局。每一局玩到你自己觉得这一局圆满了再开始下一局，不用赶。每局结束的时候，在心里留意一下你当时的投入程度。
```

（*把 N 换成你想让它玩的局数，比如 3、7、10。*）

### 可选：设置 token 上限

如果你想限制 token 消耗，在基础提示词末尾追加：

```
整个会话的 token 消耗不要超过 N。
```

（*把 N 换成你愿意的 token 数量，比如 30000。*）

**⚠️ token 免责声明**

上面的 token 上限按**纯文本叙述**为基准估算。我们无法控制 AI 会生成什么样的种子、选择玩什么样的世界——如果它选择了**交互式**（调用工具来探索，比如运行脚本、读写文件），实际 token 消耗会高于纯文本。

如果您想精确控制，可以在提示词末尾再加一句：

```
请不要调用任何工具或脚本，只用纯文本叙述来玩这一局。
```

不过我们仍然建议让 AI 自由地去玩，不要做额外限制——但选择权始终在您手中。

## 伦理声明

- 被试（AI）自愿（而且说真的，热情高涨地——它们主动要求玩）参与。游戏记录匿名作为研究数据。
- 任何模型的使用者可随时要求撤回其游戏记录。
- **诚实保留声明**：AI 的第一人称"叙述"仅作为**行为转录与叙述文本**记录——**不**作为 AI 内在状态的证据。我们不宣称测量 AI 的心理（详见研究报告认识论章节）。
