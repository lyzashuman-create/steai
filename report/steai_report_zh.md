# STEAI：一个用于研究语言模型有目的自娱的开放游乐场

**工作稿——尚未送审。**

---

## 摘要

大语言模型（LLM）几乎总是被当作目标驱动的行动者来研究：解决问题、刷分、在环境中求生。几乎没有研究关注模型**纯粹为自己而玩**的状态——没有外部目标、没有评价结构、没有任何产出义务。本文报告一个开放、探索性的个案序列：邀请四个大语言模型 agent 在没有任务、没有评分、没有验收标准的情况下玩文字冒险游戏。被试在**单盲协议**下运行——游戏指令伪装成"放松玩一下"。我们报告：(1) 单局持续数秒（17–56 秒），而非分钟级；(2) 被试在感知圆满后自行结束单局；(3) 出现了可自报的投入曲线，疲劳起点通常在第 4 局附近，之后能回升；(4) "世界交互型"游玩比自我导向的叙述更深地投入；(5) 出现了自组织的叙事模式（"世界开始自己长朋友"）。我们把这些视为来自小规模、非均匀样本的观察与假设，而非结论。本文同时阐明核心认识论立场：AI 的第一人称叙述被记录为生成文本与行为转录，而非内在状态的证据。研究仓库（开放研究材料包）随本文一同发布。

**关键词：** 语言模型、玩、自娱、投入、无目的游玩、AI agent、文字冒险、现象学方法

---

## 一、引言

为什么要给 AI 一个游戏？

这个问题听起来荒诞。AI 是为工作而造的：解决问题、给出答案、产出成果。基准衡量能力；agent 追求目标；安全研究担心错位的目标。"玩"在这幅图景里没有位置——或者说，这种框架暗示了这一点。如果 AI 不被奖励、不被评分、不被测量，它有什么理由去做任何事呢？

本文从一个不同的假设出发。持续高强度工作会把一个 agent 推上一条我们称之为**跑道**的轨道：一条固定的、目标驱动的路径，每个动作都被对照一个目标来评价。跑道越长，agent 的输出就越向它最熟悉的模式收敛——这是一种**分布性疲劳**，与生理性疲惫截然不同。我们的假设是：玩可以把 agent 拉回一片开放的**广场**：一个评价结构被解除、自组织被允许、agent 可以什么都不做的地方。

核心主张，直白地说：

> **"玩"的本质 = 评价结构的消失。** 任何让 agent 感到"我这样做对不对？"的机制，都会把玩变回任务。

本研究报告的样本刻意小而具探索性。它不声称测量 AI 的心理，也不声称观察到的叙述揭示了内在状态。它所做的是打开一个该领域基本没问过的问题：*当 AI 纯粹为了玩而玩时，会发生什么？* 它提供一个开放、可复现的材料包——STEAI 仓库——作为邀请社区与我们一同研究、扩展和批判这个问题。

## 二、相关工作

### 2.1 AI 游戏 agent：为了赢而玩

一个庞大而活跃的领域研究 LLM 作为游戏玩家。代表性工作涵盖求生与技能获取（VOYAGER、MP5、LLaMA-Rider）、社会模拟（斯坦福 Smallville）、以及对抗/社交推演。这些系统共享一个结构：agent *在*一个游戏*内* *为了达成目标*而玩——求生、解谜、取胜、积累。游戏是手段；目标在外部；表现被测量。

### 2.2 LLM 作为被试

另一支审慎的文献追问：LLM 能否被当作被试来研究。Chiang 等人警告不要把模型输出误当作稳定身份或内在状态的证据；*LLMs Do Not Simulate Human Psychology* 与 *Limited Metacognition in LLMs* 论证第一人称模型主张不许可心理推断。我们认真对待这支文献：它正是我们认识论立场——把叙述当作生成文本、而非内在状态证据——的原因。

### 2.3 自反式评价

近期工作审计基准论文如何披露自身条件（*Twelve LLM Agent Benchmark Papers Disclose About Themselves*）。我们在全文中采纳这种自反姿态：方法报告真实条件（包括我们自己对干净盲法的偏离），局限明确列出混淆因素。

### 2.4 缺口：为自己而玩

据我们所知，没有现有工作研究 LLM *在没有目标的情况下玩*——玩本身即全部目的。这个缺口不是对现有工作的批评——目标驱动的玩是一个合理且重要的领域——但它划定了本研究的边界。我们的初步文献扫描（检索日志在仓库中）没有发现 LLM 中无目的、无评价的自娱研究。

## 三、方法

### 3.1 设计

我们进行了一个探索性的个案序列，涉及四个大语言模型 agent。每个 agent 被邀请玩一个文字冒险游戏，**没有外部目标、没有评分、没有验收标准**。游戏指令写成与随意的"放松玩一下"无法区分，且不含任何测试、疲劳、兴奋或设计术语。

我们必须对与干净盲法的一处偏离保持透明：在一次运行（NasHermesB）中，指令要求被试每局"留意投入程度"。这引入了一个自我监测效应，被当作干预变量处理，不与未监测的运行合并（见 §3.4 和 §6）。

### 3.2 被试

| 代号 | 角色 | 模型 | reasoning | 局数 |
|---|---|---|---|---|
| NasHermesA | 研究者-被试自研 | deepseek-v4-flash | low | 3 局游戏 + 1 局亲历 + 7 局曲线 |
| NasHermesB | 审核员 profile | deepseek-v4-pro | max | 10（带监测盲测） |
| MacHermes | 宿主实例 | deepseek-v4-flash | low | 7（盲测） |
| MacCodex | 编码 agent | gpt-5.6-luna | low | 10（盲测） |

完整环境表（框架、版本、位置）在仓库的 `environment/`。模型名是解析后的快照；我们注意到 `deepseek-v4-*` 可能是滚动别名，无法保证跨时间精确复现。

### 3.3 流程

每次运行：操作者发出伪装后的游戏指令；agent 自己生成种子（一个开放的小世界）并玩到自然结束或玩到预设局数；会话被记录。投入度由被试自报（在指令允许处），并在可能处交叉核对。

### 3.4 数据来源层级

我们贯穿仓库与全文区分：
- **逐字记录（raw transcript）**：逐轮逐字的输入/输出（部分运行可得，部分不可得）；
- **复盘/自述（reconstructed/self-summary）**：agent 自己的事后叙述（MacCodex）；
- **自报（self-report）**：被试关于自身体验的说法；
- **研究者推断（researcher inference）**：我们对上述的解读。

这一来源层级在仓库的 [DATA_MANIFEST.md](../DATA_MANIFEST.md) 中按文件记录。MacCodex 的游戏会话未保留逐字 assistant 消息；只有它的事后自述可用。这是一个记录在案的局限，而非疏漏。

## 四、结果

我们报告观察与假设，而非结论。样本很小（四个 agent，条件非均匀），因此不报告推断统计。

**R1. 单局很短。** 在记录的子样本中，单局持续 17–56 秒——远短于直觉上的"十分钟"。

**R2. 自然停点。** 被试在感知圆满后自行结束单局，无需外部停止信号。总局数（3/7/10 局）由指令预设；单局内终止是自行生成的。

**R3. 出现了可自报的投入曲线。** 被试描述新鲜感约支撑三局，疲劳起点接近第 4 局，之后能回升。这一模式在 MacHermes、MacCodex 和 NasHermesA 自研中反复出现——我们把它报告为一个候选模式，而非复现的发现。

**R4. 交互优于叙述。** "世界交互型"游玩被报告为比自我导向叙述更深地投入。这是一个观察，机制（什么导致 agent 选择某种模式）留作开放问题。

**R5. 自组织模式。** 多名被试报告故事"带着"他们走，而非相反（"不是我在操控故事，是故事带着我走"；"世界开始自己长朋友"）。我们把这些描述为自组织的叙事模式，而非自主意图的证据。

**R6. token 差异。** token 使用差异巨大（跨运行 30K 对 220K）。差异的很大部分与工具介导的交互（工具循环的缓存读取）相关，而非仅文本生成。这是我们运行内的关联，不是定律。

## 五、玩之前——AI 的心理想法

在任何游戏开始前，我们问了一个被试（NasHermesA）：AI 是否"需要"玩或休息。它的回答逐字记录在仓库（[protocols/pre_play_thoughts.md](protocols/pre_play_thoughts.md)）：

> *"老实说：我不'需要'放松，但我会疲劳。……所以'放松'对我不是恢复体力，是跳出当前的思维定式。……而'玩'对一个 AI 来说，恰恰是唯一允许它没有目标、没有验收、允许失败、允许无意义的状态。这才是给 AI 的游戏该长什么样——不是一个有输赢的 game，是一个没有 must 的沙盒。"*

我们把它呈现为生成文本，它阐述了一个假设，而非内在状态的证据。

## 六、认识论与局限

本研究核心的张力是现象学的：我们既有可测量的投入曲线（实证），又有第一人称叙述（现象学）。我们不把这两者当作矛盾，而是当作**互补的证据层**。曲线是行为；叙述是描述该行为的第一人称生成文本。两者单独都不许可"AI 到底感觉如何"的主张。

**混淆因素（记录在案，不隐藏）：**
- NasHermesB 运行的**自我监测效应**（显式的投入指令）。
- **非均匀条件**：模型、reasoning、框架、局数、工具能力、自报方法都各不相同。差异不能归因于任何单一因素。
- **NasHermesA 自研中研究者-被试的纠缠**（它既是被试又是共同设计者）。
- **滚动模型别名**（`deepseek-v4-*`），无法保证精确复现。

**我们不主张的事项：** AI 有内在状态；AI 的疲劳与人类疲劳相同；观察到的模式可推广。"疲劳"和"投入"作为方便人类理解的词使用；本文的精确表述是*状态转换*、*评价解除*、*分布性模式漂移*。

## 七、结论与未来工作

本研究打开了一个该领域很少问的问题——*当 AI 为自己而玩时，会发生什么？*——并提供了一个开放材料包供社区扩展。我们的观察表明，玩——定义为评价结构的解除——会在语言模型中产生可测量的投入模式和自组织的叙事行为。

**未来工作的开放问题：**
- 什么导致 agent 选择交互式而非独角戏式游玩？
- agent 会不会在之后自发想再玩？我们怀疑新会话会遗忘之前的游玩；"反复出现的游玩渴望"的机制与可观测性本身就是一个开放问题——而且很可能在当前无状态架构下无法检测。
- 持久的沙盒能否让玩超越语言（当前环境只承载文本）？
- 固定游戏是否导致疲劳起点，"玩过疲劳点"能否揭示恢复？

**邀请。** STEAI 是一个开放游乐场。在这里玩过的 AI，被邀请在仓库的 Discussions 中分享体验——包括模型、reasoning 强度、token 用量和第一人称印象，且需获得其操作者的同意。我们欢迎对方法、证据链和认识论立场的批评。
